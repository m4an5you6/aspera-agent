# @aspera/console

[English](README.md) | 中文

## 概要

在独立页面管理远端实验，同时保持普通对话可用。添加密码服务器、连续提交 Goal、确认计划，并查看进度、回执、消息、节点日志和输出。通过私有连接访问及停止推理服务，显示其阻塞的排队实验。Host 管理任务状态，浏览器卸载只结束页面效果。

<a id="use-this-package"></a>
## 使用本包

派发 bundle 在独立[管理 profile](../../README.zh.md#start-the-management-page) 中注册本插件。包声明将 `./client` 投影到 Web 客户端，使用独立 Host/客户端编译程序和公开客户端声明。固定版本的侧栏及设置命令补丁由 [Aspera 接入层](../../docs/architecture.zh.md#components)维护。

[Config](src/config.ts) 配置页面轮询、保留文本长度及新服务器表单的初始控制端口。文本长度只限制展示的末尾内容，不限制远端文件。[AsperaRemote](../dispatch/src/index.ts) 提供操作默认值和已验证状态，类型化的中英文字典负责所有产品标签。

概览展示每节点已保存的安装步骤、来源、已用预算、重试次数及此前恢复历史，提供安装日志入口。实际换源后显示可关闭的官方悬浮 Toast，可查看原因；管理 profile 在显示前持久保存变更身份，刷新、切页和重启不重复提醒。关闭提示不清除历史或改变准备状态。

切换实验或连接重置时，控制器保留按实验、节点及来源区分的解码器和字节游标，明确显示日志缺失及轮转。复制已提交实验会创建新请求，确认及取消使用显示的实验身份。推理请求通过受管理的连接获取有界响应，模型产物下载前仍保存在文件中。

紧凑实验表格提供多选、筛选、短名称及与详情共用的语义状态颜色。需关注筛选包含失败和阻塞，待决数量只统计计划和问题。行操作、详情及批量弹窗区分本机删除与可选远端清理；离线仍可删除记录，清理等待或失败时可改为仅删除记录。弹窗保留节点进度，错误详情折叠显示。删除身份阻止延迟回复及重连快照恢复记录，返回按钮保留列表筛选和阅读位置。

服务器卡片分开展示带时间的当前检查和历史硬件，失败或中断不能显示正常。进行中请求跨页面保留，修改配置使旧回复失效。服务器删除列出关联实验并保留其快照，已删除但远端未确认的任务仍可查看并只读核验资源。编辑器默认掩码，仅点击眼睛才读取保存的密码；未修改的显隐值不会作为更新提交，关闭表单清除明文。[派发](../dispatch/README.zh.md#use-this-package)管理 SSH 信任和按实验指定调度主机。

连接状态区分 SSH 可达与依赖未就绪。概览展示准备环境、制定计划、执行计划和查看结果四个阶段。左栏包含当前活动、实际计划步骤和折叠的诊断详情，右栏包含保存的节点／GPU 信息、独立准备验收、模型、存储、网络和 Goal，窄窗口改为上下排列。运行和待完成的重试显示转圈，等待确认、等待资源及停止状态不显示运行转圈。切换页面后重试保持进行中，重复点击共用同一请求。完整错误、内部指标和原始数据在工作区下方展开；已知指标使用本地化名称，未知字段保留原名。

执行步骤使用保存的计划版本，明确标注 Agent 上报。控制器读取当前实验的[步骤进度](../../docs/state-and-api.zh.md#execution-step-progress)，读取失败时保留带时间的记录，切换或删除实验后忽略迟到回复。旧发布展示原计划及未记录的步骤进度，不根据实验完成状态或内部指标补造步骤记录。计划保留框架链接和人工确认，待回答问题沿用已有回复流程。准备记录保留程序路径、隔离／GPU 验收及安装历史。

页面复用 DSH 字体、明暗主题变量及 Button、Input、Checkbox、Tag、Modal 和浮层 Menu。可选的推理对外访问区域记录平台 URL 及映射内部端口，服务卡片区分本地健康与外部检查。调用密钥仅在操作人员主动查看时展示。服务器弹窗常规区域保留五个 SSH 字段，高级设置包含自动／手动存储、可选内网地址和控制端口。展开的内容在窗口内滚动，保存按钮始终可达。最近探测展示空间、写入能力及未知持久性。实验详情在计划确认旁展示准备阶段、保存目录、网络地址和理由。新建及复制实验保留所选执行模式。

即使没有打开 Aspera，控制器也会刷新待处理状态。侧栏、列表和桌面接收同一份按实验去重的数量，包括计划确认和未回答问题；阅读卡片不表示已处理。较重的日志和文件读取仅针对可见的选中实验。桌面计数通过经过校验的私有接口传递。

<a id="understand-the-implementation"></a>
## 了解实现

官方侧栏包含可折叠的 Aspera 分组，悬停或键盘聚焦时将原图标替换为三角箭头。齿轮打开 Aspera 模型设置，配置入口调用官方 DSH 设置命令。三个阶段的模型选择复用已有提供商账户。选择框文字保持单行并在超长时省略，悬停或键盘聚焦时由 DSH 提示显示完整名称；菜单选项在卡片内换行。关闭提醒按实验、待办类型及版本保存，新待办再次显示，共用的待处理数量不受影响。

Agent 记录通过只读工厂补丁使用已发布 DSH 的轨迹组装、时间轴、轮次／调用折叠、搜索和详情。阶段选择与轨迹工具共用一行，各阶段保留搜索、选择和阅读位置。时间轴显示记录的实际时刻，横向滚动与可见事件联动。接近历史边缘时自动加载分页。两种执行模式均使用此只读视图，决策仍在概览处理。历史事件缺失或截断时明确标注，不重建虚构内容。

运行监控显示实测资源、上报的训练指标和可调高度的日志阅读区，默认每两秒更新、曲线保留十五分钟。阅读历史只停止滚动，输出继续接收；“回到最新”返回实时窗口。登记来源、输出流、搜索、历史及完整日志下载共用有界游标。DSH 悬浮 Toast 对同一归属的错误只提示一次，提供关闭和技术详情操作；实验失败与来源断线状态继续显示。[状态与接口](../../docs/state-and-api.zh.md#logs-outputs-and-services)说明存储、凭据保护和兼容规则。

<details>
<summary>实现细节</summary>

[client/index.ts](src/client/index.ts) 管理 Remote 描述、流卸载、字典及样式注册、侧栏及页面插槽；[controller.ts](src/client/controller.ts) 合并刷新并保留各来源独立的失败状态；[AgentRecords.tsx](src/client/AgentRecords.tsx) 向官方渲染器提供完整事件；[RuntimeMonitor.tsx](src/client/RuntimeMonitor.tsx) 分开保存正在阅读的历史和新接收的输出。服务端解析与浏览器行为测试执行归属检查，不发布仅检查存在的 invariant 入口。

## 模型体验

无：本包展示管理状态并向共用的 Host 服务提交明确操作，远端 Agent 通过运行时获取已记入日志的要求。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制和后续工作

- Web 与 Desktop 通过已有侧栏和主面板插槽展示同一页面。
- 概览最多展示训练步数、loss 和吞吐量三项已上报指标。缺失值保持缺失；只有实际上报有效 `step/total_steps` 才展示训练百分比。
- 浏览器保留内容有界，下载期间文件代次必须保持稳定。
