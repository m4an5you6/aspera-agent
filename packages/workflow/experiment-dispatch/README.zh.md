# @deepseek-ai/dsh-experiment-dispatch

[English](README.md) | 中文

## 概述

Web 实验与模型工具共用任务服务。每个实验固定保存服务器、源码版本、输入和独立派发会话。调度主机收到所需源码、输入和私有凭据后确认接管，其队列独立于本机进程继续执行。完整回执包含“本机派发完成，远端实验已接管”，仅完成编号和版本仍匹配的本机 Goal。

## 使用本包

在 Web 打开**实验 → 服务器 → 添加服务器**，填写名称、SSH 地址、端口、用户名、密码和私有远端目录。联合训练还需填写其他节点可访问的训练网络地址。第一台服务器固定兼任调度主机，也可参与训练；不能通过此表单迁移其地址、控制端口和状态目录。

连接前在 DSH 主机上核验 SSH 主机密钥。密码连接使用已核验的 known_hosts 文件，保留密码空白字符，不自动改用密钥。密码保存在凭据服务中，不进入服务器记录或浏览器查询结果。编辑时密码留空会保留已保存值。模型服务凭据需单独配置；提交前请配置 agentCredentialRefs 选中的凭据引用。

选择**新建实验**，输入 Goal，选择一台或多台服务器，可附加文件或填写本地文件绝对路径。全部所选节点共同执行该实验。提交后立即出现准备记录，可继续提交下一个 Goal。本地路径必须位于配置的 dataRoots 下；浏览器附件单独暂存。输入文件不能重名。

详情显示排队原因、完整回执、执行会话、节点日志、错误和输出信息。刷新按已保存的实验编号核对状态；取消发送到原调度主机。下载通过一次性地址按需流式传输所选文件。复制为新实验会创建新编号并允许修改，浏览器附件需重新选择。

原单服务器设置会一次性初始化服务器列表。旧密钥目标未显式填写用户名时，会从本机 OpenSSH 配置解析登录名。历史回执在旧设置页面保留原目标。普通对话的 /goal 指令仍在每个会话中维护一个当前 Goal；实验列表通过创建独立会话支持多个 Goal。

experiment-dispatch 配置保留 prepare_experiment_environment、submit_experiment、get_experiment_status 和 cancel_experiment，供原单目标任务使用。多服务器工具列出获准服务器编号，并通过与 Web 相同的任务服务派发。凭据缺失、主机密钥未知、构建失败、隔离不可用或 GPU 不可用都会停止准备。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

experiment_fleet 存储域保存固定调度主机列表和各实验不可变部署设置。稳定编号去重浏览器重试；工具提交还绑定调用方会话、Goal 编号及版本。准备过程生成按内容寻址的源码归档，安装不可变版本，移交输入和私有节点凭据，再提交协议 2 请求。先持久保存回执，再完成 Goal 并刷新会话。刷新可在本机重启后找回丢失的回执，不会再启动一个实验。

移交给调度主机的凭据保存在仅所有者可访问的 secrets 目录。源码归档排除凭据、依赖和构建产物。运行工具与浏览器查询仅暴露凭据引用。已有远端控制进程保留其运行版本；每次执行使用自己的版本和目录。空闲旧接收端关闭后，对应节点才启用协议 2；繁忙接收端会阻止升级。

</details>

## 模型体验

### 派发要求与回执

#### 模型看到的内容

本机系统指令区分排队接管与实际执行，要求明确服务器授权、保留用户约束并原样报告 `handover` 字段。活动派发 Goal 拒绝提问、等待审批和 Agent 发起的插件变更，插件重载后仍生效。

#### Token 影响

固定工具定义与指令增加请求 Token；回执将任务相关的服务器和执行证据写入会话历史。

#### KV Cache 影响

定义保持稳定，每份回执仅追加到所属会话历史。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 一个远端调度主机拥有队列，不支持自动迁移或故障切换。

- 接管前关闭本机进程会中断准备。结果不明的提交必须按已保存编号刷新或取消。

- 真实多 GPU 训练和关闭本机后的继续执行，需要在可访问的 GPU 服务器上验收；本地测试不能证明这些结果。
