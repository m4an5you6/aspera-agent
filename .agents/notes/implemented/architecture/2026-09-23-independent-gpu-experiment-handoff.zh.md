# Agent Note: 独立 GPU 实验接管

Status: implemented

[English](2026-09-23-independent-gpu-experiment-handoff.md) | 中文

## 问题

本机编码 Agent 可以准备 GPU 实验，但在操作者关闭终端或连接中断后，不能继续管理训练生命周期。SSH 命令、本机 Session 和远端训练各有不同的生命周期。接管回执丢失后重复提交，还可能启动第二次训练。

远端工作端需要文件限制和 GPU 访问，不能假定服务商管理的容器允许嵌套 Docker，或具备可用的内核沙箱。现有 [Goal 域](../feature/2026-07-19-persisted-same-session-goal-domain.zh.md)在 Session 中记录续行，但刻意不在进程重启后自动授予执行权限。

## 决定

本机 `experiment-dispatch` profile 将当前源码打包并计算摘要，在远端独立版本目录构建，实测 bwrap 文件限制和分配的 NVIDIA 设备，再通过短时 SSH 隧道连接需要认证的回环地址接收端。`experiment-worker` profile 是独立运行的 DSH 进程，拥有自己的 Session、Goal、工作目录、日志和存储域提交记录。SSH 连接只承载控制通信，不拥有 Agent 的生命周期。

派发端先保存提交编号再发送。接收端在创建 Agent 前预留编号，只有在 Session 刷新且接管记录持久保存后才确认。同一编号和相同内容的重试返回已有回执，包括终态；内容冲突则拒绝。未完成的预留记录在重启后变为 `interrupted`，不会再次启动训练。接收记录负责提交身份和工作进程生命周期；Session 仍是 Goal 历史的权威来源，遵循 [Goal 事件决定](2026-07-31-goal-owned-durable-events.zh.md)。

无人值守 profile 拒绝人工提问和审批，禁用计划审批及能力扩展，并允许 Goal 在第一次续行后报告阻塞。工作端不加载进程内文件工具，使命令和文件操作遵循同一 bwrap 策略。私有凭据位于源码快照之外，并对受限命令隐藏。这在[沙箱决定](../feature/2026-07-06-sandbox.zh.md)上增加显式 GPU 设备授权和私有读取遮蔽；不宣称提供网络隔离。

## 考虑过的替代方案

**直接通过 SSH 命令运行训练。** 控制连接断开可能结束或遗留远端命令，也没有支持幂等重试的持久认证回执。

**让 Agent 控制 Docker daemon 或使用无限制执行。** Docker 控制权限超过单个实验的需要；沙箱不可用时必须停止准备，而不是静默放宽文件限制。

**把远端提交伪装成人工消息。** 这会让机器来源的工作在 Goal 和交互策略中获得人工权限。接收端通过服务创建 Goal，并记录插件来源的初始消息。

## 后果

一个工作端同时只接管一个活跃实验。本机 Goal 可在接管时结束，远端 Goal 继续运行。源码版本启用后保持不变；准备失败会保留先前可用版本。凭据和数据按显式配置单独传输。工作进程重启后报告中断，不自动重启训练；已完成实验的状态仍可从持久记录和产物路径读取。需要认证的 HTTP 控制服务和模型凭据属于可信工作端基础设施，不位于模型的文件沙箱内。
