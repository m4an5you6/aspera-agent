# 删除本机实验后的远端任务恢复

[English](guide.md) | 中文

## 变更

删除本机实验后，程序保留私有远端任务身份，直到全部原节点确认释放。服务器卡片展示待释放的已删除任务，并提供核验或明确中断入口。核验不停止活动任务。中断保留现存环境、模型、数据和日志。

重新打开 Aspera 后，未完成操作沿用原回执恢复。控制进程离线时，准备修复工具使用与手动中断相同的身份和退出检查。原提交身份缺失、原节点不可达或进程归属不明确时，保留占用并报告缺失证据。

既有删除日志继续可读。历史任务在恢复前需要核验原提交、固定发布和节点分配。已删除实验继续保持删除状态。程序不自动重新训练。

## 迁移

私有 `aspera_remote_tasks` 第 1 代存储独立于 fleet 第 6 代保存连接引用和提交摘要。提交协议 4 和 Session 格式保持不变。生成的 Remote 客户端包含远端任务状态和收尾操作；使用更新后的 dispatch 包重新构建客户端。

通过服务器卡片的“核验并释放”处理已删除任务。“中断远端任务”明确允许停止该任务。受阻结果保留占用并列出缺失证据；重试沿用原操作。连接检查保持只读，不进行任务收尾。
