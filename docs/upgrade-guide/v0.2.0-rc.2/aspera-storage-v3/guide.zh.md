# Aspera 存储与网络准备

[English](guide.md) | 中文

## 变更

Aspera 0.1.1 使用独立于应用版本的协议和存储第 3 代。新服务器默认自动选择存储位置，内网地址可以留空。准备阶段在远端接收之前记录所选挂载、目录及验证后的网络地址。生成的 Remote 使用方需使用对应的扩展构建。

## 迁移

1. 替换控制服务前，结束已有远端任务并确认进程清理。历史协议第 1、2 代回执保留原始版本字段和摘要。
2. 安装完整的 Aspera 0.1.1 构建。已有显式远端目录保留原布局；新服务器使用私有控制状态及独立选择的实验存储位置。
3. 将中断的旧准备记录复制为新实验，以使用自动准备。在实验详情中检查保存的目录和网络结果。
4. 可选的推理对外映射要求调度主机和节点使用此构建（`public-inference-v1`）。结束已有工作并停止旧控制服务后再部署新构建。添加平台 HTTPS 地址及映射内部端口，再创建或复制实验；已提交任务保留原设置。缺少这些可选字段的旧记录仍可读取。
5. 分发多个应用版本为 0.1.1 的构建时，保留构建标识及可执行文件／运行时校验值。打包提供完整应用目录，不生成 ZIP。
